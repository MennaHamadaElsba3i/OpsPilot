# OpsPilot — Operations Management Dashboard

OpsPilot is a modern operations management dashboard built with **React, TypeScript, and Tailwind CSS** to monitor, track, and manage operations efficiently.

## Why OpsPilot?
Effective operations management helps teams monitor progress, identify failures, and track tasks in one place. OpsPilot provides a centralized interface for improving visibility and simplifying workflow management.

## Key Features
- **Operations Overview:** Track 5,200+ operations and their statuses.
- **Search & Filtering:** Find operations quickly by name or ID and filter by status.
- **Sorting & Pagination:** Organize and navigate large datasets efficiently.
- **Operation Details:** View operation information and update statuses.
- **URL State & Navigation:** Preserve filters and search state across navigation.
- **Reliable Data Fetching:** Handle loading, errors, and out-of-order search responses.
- **Mock API:** Simulate network latency and request failures.

## Tech Stack
React · TypeScript · Vite · Tailwind CSS · TanStack Query · React Router · Vitest · Playwright
